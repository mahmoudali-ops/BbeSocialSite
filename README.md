🚀 BbeSocial – Customer Service Platform

BbeSocial is a fully deployed, production-ready customer service platform built with a strong focus on scalability, security, SEO optimization, and full administrative control.

🌍 Live Website: https://www.bbesocial.com/

🧩 Overview

The platform consists of two fully integrated parts:

🌐 Client Website

Modern responsive UI (Mobile / Tablet / Desktop)

Multi-language support (EN / DE / NL / AR with RTL)

Dynamic services & pricing sections

SEO-optimized pages

Server-Side Rendering (SSR)

Dynamic meta tags, Open Graph & sitemap

🛠️ Admin Dashboard

Full content management (services, pricing, sections)

Multi-language content control

Media & image management

Navigation & links control

Website branding customization

Role-based protected access

All website content is fully dynamic and controlled through the dashboard.

⚙️ Backend – ASP.NET Core (.NET 8)
Architecture

Clean Layered Architecture (API / Application / Domain / Infrastructure)

Repository + Unit of Work + Specification Pattern

Entity Framework Core + SQL Server

DTOs + AutoMapper

Migrations & Data Seeding

Security

JWT Authentication stored in HttpOnly Secure Cookies

ASP.NET Core Identity

Role-Based Authorization

Secure CORS configuration

Input & Token validation

Performance

Redis caching with custom attributes

Server-side pagination

Optimized async queries

Image optimization (WebP & compression)

Integrations

SMTP / Zoho email integration

Exception middleware & structured logging

Production-ready configuration setup

💻 Frontend – Angular 17 (SSR)

Standalone Components Architecture

Angular Universal (SSR) + Client Hydration

Functional Guards & Interceptors

Cookie-based authentication

Reactive Forms with multi-language support

Lazy loading (Client & Admin areas)

Signals + RxJS state management

RTL support

Dynamic SEO meta management
